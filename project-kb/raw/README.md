# Raw Data Sources

This directory contains source material that feeds the knowledge base. Each subfolder represents a source type.

## Current Sources

| Source | Folder | Description |
|--------|--------|-------------|
| Project docs | `../docs/` | Existing project documentation (not copied — referenced in place) |
| Working sessions | (inline) | Learnings captured during Claude working sessions |

## Adding New Sources

When a new type of source material is identified (e.g., email threads, API responses, meeting notes), create a subfolder here and document it in this table.

## Notes

- Raw data is reference material — it feeds wiki compilation and playbook extraction.
- Large files should be summarized rather than stored verbatim.
- Sensitive data (credentials, PII beyond what's needed) should NOT be stored here.
