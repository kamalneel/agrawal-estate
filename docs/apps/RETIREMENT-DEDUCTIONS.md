# Retirement Deductions App

## Goal

Optimize retirement account contributions across 401(k), IRA, HSA, and other tax-advantaged accounts. Maximize tax deductions while building retirement wealth.

---

## Features

### Current Features

1. **Contribution Tracking**
   - 401(k) contributions (traditional and Roth)
   - IRA contributions
   - HSA contributions
   - Employer matching

2. **Limit Monitoring**
   - Annual contribution limits
   - Catch-up contribution eligibility
   - Over-contribution warnings

3. **Optimization Recommendations**
   - Maximize employer match
   - Traditional vs Roth allocation
   - HSA triple tax advantage
   - Mega backdoor Roth

4. **Tax Impact**
   - Deduction value calculation
   - Tax bracket impact
   - MAGI implications
